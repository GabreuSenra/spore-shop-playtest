01 / EXPEDIÇÕES

O rendimento de cada região

Mediana por run · inclui runs com zero

Mediana de ouro por região

Ouro efetivamente recebido na venda da carga. Cada região reúne todas as suas runs nos filtros atuais.

Passe o mouse ou selecione uma barra para ver o valor exato e a amostra.

Mediana de relíquias por região

Relíquias estouradas na expedição. Cada relíquia conta uma vez, independentemente de quantos fragmentos gerou.

Passe o mouse ou selecione uma barra para ver o valor exato e a amostra.

Mediana de fragmentos por região

Fragmentos coletados. A amostra inclui somente runs que registraram essa métrica; históricos antigos não contam como zero.

Mediana é o valor central das runs; com quantidade par, usamos a média dos dois valores centrais. n = runs observadas. Sem amostra aparece como —.

Ouro recebido por run

Relíquias estouradas por run

As mesmas runs, na mesma ordem e com as mesmas cores de região do gráfico de ouro.

Quantidade exata de fragmentos coletados. — indica que a run não registrou essa métrica.

Os filtros acima também se aplicam ao save. Cada barra representa uma run válida recebida; runs excluídas por debug ficam fora. Em históricos longos, role os gráficos horizontalmente.
